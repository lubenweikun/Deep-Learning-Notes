
我们想让机器预测复杂的事物，线性叠加，最终都是简单的线性关系      

激活函数:为什么需要？   不同的任务需要不同的激活函数，接收信号 -> 处理 -> 决定是否激活。激活函数----神经元

在数学里，线性模型（一次函数）能解决的问题极其有限。
而增加非线性激活函数，实际上是做了一个**空间映射**：它把原始数据所在的空间，映射到了一个更高维、可以被“扭曲”的特征空间。在这个新空间里，原本纠缠在一起的复杂问题，可能就变得可以被“线性可分”

类似的简单例子   阈值函数（阶跃函数Step Function）：当大于某个阈值为1，小于某个阈值为0，这样就对原始数据进行了一次分类

激活函数的作用也是如此，把线性数据映射到高维空间（并非物理上的高维，而是数学中的高维）

前向传播——计算损失——反向传播——梯度下降与参数更新

前向传播：用当前的参数，算出预测值

计算损失：算出损失，可以用均方误差（MSE）

反向传播：*W*(权重) →r(线性组合) → a(激活值) → y(预测值) →*L*(损失)

PyTorch代码:

```python
for epoch in range(10000):        # 循环一万次（反复训练）
# ===== 1. 前向传播 =====
y_pred = model(x)             # 算出预测值 y_pred=28，并保存中间变量 a, r

# ===== 2. 计算损失 =====
loss = loss_fn(y_pred, y_true)# 算出 L=162

# ===== 3. 反向传播 =====
optimizer.zero_grad()         # 清空上一轮的梯度（防止累加）
loss.backward()               # PyTorch 沿着计算图自动执行链式法则！
                              # 自动填满所有参数: W.grad=144, b.grad=72, c.grad=126, d.grad=18

# ===== 4. 梯度下降与参数更新 =====
optimizer.step()              # PyTorch 执行: W = W - lr * W.grad
                              # 自动把 W 从 3 改成 1.56，b 从 1 改成 0.28...
                              
/关于θ,g的解释。θ是所有参数的“集合”，本身是一个巨大的向量。类比封装函数，这里是封装了参数。g是梯度向量，反向传播算出的所有偏导数，按照 θ 的顺序拼成一个同样长度的向量g。θ 和 g 里的数字是一一对应的。                 
# 1. θ 已经存在于 model.parameters() 里了（打包完毕）
# 2. 算梯度：反向传播
loss.backward() 
# 这一行执行后，PyTorch 会把算出来的所有偏导数，存进每一个参数自己的 .grad 属性里。
# 此时，如果你把所有参数的 .grad 拿出来拼在一起，它就是 g！

# 3. 更新参数
optimizer.step()
# 优化器遍历每一个参数 θ_i，执行 θ_i = θ_i - lr * θ_i.grad
# 于是，新的 θ 诞生了！
```
为什么要引入批次？一组数据是并行运算的，如果有几万条数据，若一次性塞入运算，则会难以运行。分批次运行能很好的使用cpu的并行效果来进行运算。

批次：第一个批次内部并行计算，各批次之间串行运算，第一个批次更新完毕得出θ1,第二批次就使用θ1来进行运算。

更新：算完一个批次的数据就计算梯度，更新参数

回合：全部批次更新完，为一个回合

过拟合：模型在训练数据上的误差持续降低，但在未参与训练的测试数据上的误差反而开始升高，导致泛化能力下降的现象。也就是模型为了在训练集上把损失降到极低，连数据里的噪音、巧合和特例都背了下来，但是并不适用于测试集，所以在测试集中表现过差。

早停法（Early Stopping）：发现测试集损失开始上升，就立刻停止训练，退回测试集表现最好的那一版。

用一层中各个神经元是独立的，不同层之间的神经元构成神经网络，随着层数的增多，也被称为深度学习，每一层被称为隐藏层。


训练集损失很大：模型偏差（模型太简单，灵活性不够）。解决方法：增加层数、增加神经元、加特征

测试集损失很大：过拟合。解决方法：早停

深层网络优化问题（优化困难）：如果浅层模型表现得很好（证明模型灵活性够了，不是模型偏差），但深层模型训练损失反而升高。优化算法（梯度下降）在深层网络中失效。

判断模型问题流程：评估训练集损失--如果训练损失很高

模型偏差（Model Bias）：

判断方法：用相同的数据，跑一个更简单的传统模型或极浅的网络。如果浅层模型表现很好，说明数据没问题，是当前深层网络能力不足；如果浅层模型表现也很差，说明模型表达能力不够。

解决路径：增加输入特征、增加模型层数、增加神经元宽度。

优化困难（Optimization Failure）：

判断方法：对比深度不同的网络。如果10层的训练损失反而高于5层，证明不是模型偏差，而是梯度下降在深层网络中失效了。

解决路径：更换优化器、调整学习率（、引入残差连接（ResNet）、加入 Batch Normalization。

如果训练损失很低：

说明模型已经能很好地拟合训练数据。

第二步：评估测试集损失。如果验证集损失很高（远高于训练损失）：这是典型的过拟合

如果都不理想：

检查数据（标签、分布、清洗）。检查超参数（学习率、批次大小）

分类：预测一个类别，独热向量         Softmax函数把原始得分变成概率分布  Softmax被称为分类器或输出层函数

分类损失：均方误差和交叉熵  均方误差再一些情况下会卡住，分类任务不能用均方误差必须使用交叉熵
